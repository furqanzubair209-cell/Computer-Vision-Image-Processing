---

## 📌 Overview

This project explores fundamental concepts of digital image processing and computer vision. It provides practical implementations of commonly used image-processing operations and demonstrates how these techniques affect image quality and representation.

The project is designed as part of a Computer Vision academic assignment and focuses on building a strong foundation in image processing using Python.

---

## 🚀 Features

- Image loading and visualization
- RGB image processing
- Grayscale image conversion
- Gaussian blur / image smoothing
- Histogram analysis
- Histogram equalization
- Basic image enhancement
- Image manipulation using OpenCV
- Numerical image processing with NumPy

## ⚙️ Installation

**1. Clone the repository**
```bash
git clone https://github.com/furqanzubair209-cell/computer-vision-image-processing.git
```

**2. Navigate to the project directory**
```bash
cd computer-vision-image-processing
```

**3. Install dependencies**
```bash
pip install -r requirements.txt
```

Or install the required libraries directly:
```bash
pip install opencv-python numpy matplotlib jupyter
```

---

## ▶️ Usage

Start Jupyter Notebook:
```bash
jupyter notebook
```

Open `Computer_Vision_Assignment_1.ipynb` and run the cells sequentially to explore the implemented image-processing techniques. Alternatively, run the standalone script:
```bash
python computer_vision_assignment_1.py
```

## 🧠 Concepts Covered

**1. RGB Images**
Understanding how digital images are represented using the Red, Green, and Blue (RGB) color channels.

**2. Grayscale Conversion**
Converting a color image into a grayscale representation to simplify image analysis and processing.

**3. Gaussian Blur**
Applying Gaussian smoothing to reduce image noise and remove fine details.

**4. Histogram**
Analyzing the distribution of pixel intensity values within an image.

**5. Histogram Equalization**
Enhancing image contrast by redistributing pixel intensity values.
